# cachy

Moves files from a [mergerfs](https://github.com/trapexit/mergerfs) cache disk to the backing storage pool once cache usage crosses a threshold.

cachy is a Rust rewrite of, and is inspired by, [mergerfs-cache-mover](https://github.com/monstermuffin/mergerfs-cache-mover) by MonsterMuffin. It adds new functionality on top of that project.

## Status

Early development. Nothing works yet.
